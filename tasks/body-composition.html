체성분을 기록하고 변화 확인하기

측정값과 조건을 함께 남기고, 비교할 기록을 고릅니다.

서비스 화면 사용해 보기 ↓프로토타입 열기 ↗

프로토타입 하단 또는 왼쪽 메뉴에서 체성분 기록을 선택하세요. 새 측정값 입력 화면은 없습니다.

이런 순간에 필요합니다

사용자의 상황

훈련 직후 저녁에 체성분을 쟀더니 골격근량이 평소보다 높게 나왔습니다. 실제 변화인지, 측정 조건의 차이인지 확인하고 싶습니다.

풀고 싶은 문제

조건이 다른 측정값이 섞이면 숫자가 올라도 어떤 변화인지 판단하기 어렵습니다.

사용자는 이렇게 이어갑니다

  1. 측정값 기록

    측정 날짜·조건·체중·골격근량을 함께 남깁니다. 새 측정값 입력은 확장 설계입니다.

  2. 조건 확인

    아침 공복인지, 저녁 훈련 직후인지 기록별 맥락을 확인합니다.

  3. 비교 대상 선택

    같은 조건의 기록을 모아 보고, 해당 기록의 추세 포함 여부를 선택합니다.

  4. 변화 확인

    선택한 조건의 추세를 확인합니다. 추세에서 제외해도 원본 측정값은 보존합니다.

이 과업을 마치면

측정 조건을 고려해 변화를 읽고, 비교에 사용한 기록을 다시 확인할 수 있습니다.

현재 구현 범위

기존 체성분 목록·상세·조건 필터·추세 포함 설정이 구현되어 있습니다. 새 체성분 측정값 입력은 이번 소개의 확장 설계이며 현재 프로토타입에서는 제공하지 않습니다.

이 소개의 근거와 데이터 보기

body.csv: 10/19 아침 공복 36.5kg, 10/22 저녁·훈련 직후 37.0kg, 10/26 아침 공복 36.5kg. 10/22 값을 측정 오류나 실제 근육 증가로 단정하지 않습니다.

가상 프로필의 기록을 바탕으로 설명한 소개 자료입니다. 위 흐름에는 확장 설계가 포함될 수 있습니다.
