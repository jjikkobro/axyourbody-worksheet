## 2) 작업 세부 규칙
- 화면을 전수 점검해 `calm-coach-review.md`에 관찰→사용자 영향→수정→검증을 기록한다. 추측은 짐작으로 표시한다.
- AI slop의 판정 기준: 작업과 무관한 표어, 같은 뜻의 반복 문장, 대상·결과가 불명확한 행동, 정보 중요도와 무관한 카드·장식·강조, 실제 동작과 다른 성공 문구. 단순한 색 선호를 결함으로 판정하지 않는다.
- 각 화면의 버튼·입력·필터·링크·상태 시연·닫기·뒤로 가기를 목록화한다. 조건부로 나타나는 조작도 포함한다.
- 정상 경로뿐 아니라 입력 오류, 편집 취소, 미저장 이탈 수락/거절, 저장 오류 재시도, 새로고침 후 보존, 저장 불가 시 이번 실행 한정 표시를 확인한다.
- 계획·몸 상태·체성분 설정·상담 연결의 편집 내용을 다른 화면의 저장이나 폐기와 혼동하지 않는다. 오류 후 현재 입력을 보존한다.
- 원자료·고정 AI 예시·사용자 입력을 구분하고, 원본 수치·측정 조건·사용자 선택권을 유지한다. 기존 사용성 성과를 재사용해 현재 성공으로 보고하지 않는다.
- AZTKS APPLY로 구현하고 EVALUATE로 지시문·최종 보고의 A/Z/T/K/S를 자체 검토한다. 독립 리뷰 또는 실제 사용자 평가로 표현하지 않는다.
- 새 회귀는 변경한 실제 동작을 검증한다. 기존 테스트는 의미가 바뀐 문구에 한해서 근거를 남기고 보완한다.
