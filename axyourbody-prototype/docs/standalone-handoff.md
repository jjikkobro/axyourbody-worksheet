## 실행

`../prototype-merged.html` 한 파일을 브라우저에서 직접 연다. 별도 빌드·서버·CDN 연결이 필요 없다. 크기 약 325KB이며 HTML·CSS·JavaScript·SVG 아이콘·한글 글꼴·가상 원본 데이터가 파일 안에 포함되어 있다.

## 반영 범위

- Clear Guidance의 밝은 표면·초록 강조·정돈된 정보 위계를 기준으로 구현했다.
- 필수 화면 7개: 운동 계획, 오늘 운동 계획, AI가 제안한 운동 계획, 체성분 기록, 날짜별 체성분 기록, 지난 상담, 상담 상세.
- 부수 상담 입력은 별도 대화상자로 제공한다.
- 데스크톱의 왼쪽 메뉴와 모바일의 하단 5개 메뉴를 하나의 반응형 파일로 구성했다. 운동 일지·운동 목표는 준비 중으로 표시한다.
- 모바일 운동 정보는 종목별 카드로 바뀐다. 전체 페이지 가로 스크롤을 만들지 않는다.
- AI 제안은 저장 전 초안으로 전달하며, 사용자가 저장해야 계획에 반영한다.
- 컨디션은 미입력으로 시작한다. 수면 CSV 컨디션과 사용자 입력을 구분한다.
- 체성분 조건·날짜·추세 포함 여부 필터, 추세 포함 저장, 원본 보존을 구현했다.
- 상담은 빈 상태로 시작하며, 선택적으로 가상 예시를 불러오거나 사용자가 직접 원문을 입력할 수 있다. 오늘 계획 연결은 계획 수치를 변경하지 않는다.
- 실제 AI·의료·코치 서비스에는 연결하지 않았다. 계획·상담 샘플은 가상이라고 표시한다.

## 출처와 구현 선택

- 기능 기준: SCREEN_SPEC.md, context/service-structure.md, context/screen-flow.md, docs/grip/GRIP_REGISTER.md.
- 시각 참고: stitch-review/clear-guidance/S01.html~S03.html 및 design/DESIGN-clear-guidance.md.
- 과업 2·3의 화면은 명세를 바탕으로 이번에 새로 구현했으며 Stitch 원본이 있는 것처럼 표시하지 않는다.
- 시연 기준일은 2026-10-29다. 전날 하이록스 70분·RPE 8, 해당일 수면 7.8시간·컨디션 4는 포함한 가상 CSV와 일치한다.
- 오늘 예정 운동의 무게·세트는 표시된 시연용 샘플이다. 원본 수행 기록을 실제 미래 계획으로 간주하지 않는다.
- 체성분 값과 조건은 body.csv 원본을 포함하며 날짜 간격을 반영한 SVG 추세로 보여준다.
- Noto Sans KR 400·600·700의 필요한 문자 부분집합을 포함했다. 전체 SIL Open Font License 1.1은 HTML의 embedded-font-license 블록에 포함한다. 사용자가 새로 입력하는 문자 중 포함되지 않은 글자는 시스템 글꼴을 사용한다.

## 저장

변경 내용은 이 브라우저의 localStorage(`axyourbody-clear-guidance-v1`)에만 저장한다. 서버 저장·계정 동기화는 없다. 파일 URL의 저장 지원과 보존 범위는 브라우저에 따라 다를 수 있다. 저장을 사용할 수 없으면 화면 상단에 안내하고 현재 실행 중에만 상태를 보존한다.
