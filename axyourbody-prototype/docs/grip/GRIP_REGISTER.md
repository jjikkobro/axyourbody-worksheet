## T1 결정 근거와 적용
- 사용자 응답: 과업 완료 기준 (권장): 필수 화면을 좁히고 보조 기능은 부수로 제안합니다.
- 핵심 과업 1~3의 완료에 반드시 필요한 화면만 필수로 분류한다. 새 기록 입력·이력 관리 등 보조 기능은 부수 후보로 제안한다.
- 검색·패널·확인창은 해당 화면의 내부 기능으로 기록하며 독립 화면 수에 중복 산입하지 않는다.
- 부수 분류는 이번 핵심 과업의 화면 구성 기준이며 서비스 전체에서 기능을 삭제한다는 의미가 아니다.

## T2 결정 근거와 적용
- 사용자 응답: 3개 화면 (권장): 운동 계획 → 오늘 운동 계획 → AI 제안 검토로 나누고 오늘 계획에서 저장 내용을 확인합니다.
- 과업 완료: 사용자가 무게·세트 유지 또는 변경을 선택하고 계획에 저장한 뒤 오늘 계획에서 저장 내용을 확인한다. 운동 시작은 후속 행동이다.
- 필수 독립 화면: 운동 계획, 오늘 운동 계획, AI가 제안한 운동 계획.
- 몸 상태 입력·무게와 세트 편집은 내부 패널로 둔다. AI를 이용하지 않고 직접 결정하는 분기를 제공한다.
- 화면별 지표는 T5에서 확정했다.

## T3 결정 근거와 적용
- 사용자 응답: 2개 화면 (권장): 체성분 기록 목록·추세 → 날짜별 상세 → 목록·추세로 돌아와 확인합니다. 조건 필터는 내부 기능으로 둡니다.
- 필수 독립 화면: 체성분 기록, 날짜별 체성분 기록. 목록과 추세는 같은 화면에 둔다.
- 완료: 측정 조건을 확인하고 추세 포함 여부를 저장한 뒤 목록·추세에서 반영 여부를 확인한다.
- 원본 측정값은 보존한다. 조건 차이를 실제 근육 증가나 측정 오류로 단정하지 않는다.
- 화면별 지표는 T6에서 확정했다.

## T4 결정 근거와 적용
- 사용자 응답: 오늘 계획 연결까지: 상담 상세에서 오늘 운동 계획을 선택해 연결하는 내부 기능을 필수에 포함합니다. 새 상담 저장은 부수로 둡니다.
- 필수 독립 화면: 지난 상담, 상담 상세. 검색·필터와 계획 선택·연결 확인은 내부 기능이다.
- 완료: 원하는 상담과 결론·당시 맥락을 확인하고, 사용자가 선택한 오늘 운동 계획에 상담 연결을 저장한 뒤 연결된 계획을 확인한다.
- 상담 연결은 참고 자료의 연결이며 운동 계획의 무게·세트 변경이나 운동 시작·완료를 의미하지 않는다.
- 새 상담 저장은 부수 후보다. 실제 상담 원문이 없으므로 빈 상태와 가상 예시를 구분한다.
- 기존 관계의 한 상담당 선택적 계획 1개 연결을 유지한다. 이미 다른 계획에 연결된 상담은 자동 재연결하지 않고 기존 연결을 알린다. 여러 계획 연결은 기존 문서에 따라 별도 검토한다.
- 화면별 지표는 T7에서 확정했다.

## T5 결정 근거와 적용
- 사용자 응답: 성공률 중심 (권장): 세 화면에 제안한 성공률을 적용하고 성공 건수/시도 건수도 함께 적습니다.
- 운동 계획: 오늘 계획 찾기 성공률.
- 오늘 운동 계획: 계획 결정·저장 확인 성공률. 직접 결정과 AI 제안 경로 모두 포함한다.
- AI가 제안한 운동 계획: 제안·근거·한계 구분 성공률. 제안 거절도 이해 기준을 충족하면 성공이다.
- 성공률은 성공 테스트 수 / 해당 테스트 시도 수 × 100으로 계산하고 성공 건수/시도 건수를 함께 기록한다. 미실시와 시도 0건은 미측정으로 남긴다.
- 목표 수치와 실제 결과는 측정 전 비워 둔다. 판단 근거와 화면별 성공 조건은 worksheet.md의 T5와 화면 표에 기록했다.

## T6 결정 근거와 적용
- 사용자 응답: 성공률 중심 (권장): 비교 성공률과 추세 포함 설정 저장 성공률을 적용합니다.
- 체성분 기록: 같은 조건의 추세 비교 성공률. 지정한 측정 조건으로 비교하고 조건이 다른 수치를 같은 조건의 변화로 해석하지 않아야 성공이다.
- 날짜별 체성분 기록: 추세 포함 설정 저장 성공률. 사용자가 고른 설정의 저장·목록 및 추세 반영·원본 측정값 보존을 모두 확인한다.
- 포함·제외 중 어느 선택이든 의도대로 반영되면 성공이다. 성공 건수/시도 건수와 성공률을 함께 기록하며 실제 결과와 목표 수치는 미정이다.

## T7 결정 근거와 적용
- 사용자 응답: 성공률 중심 (권장): 지난 상담도 원하는 상담 찾기 성공률로 측정하고, 위 표의 필수 2개·부수 제안 1개를 확정합니다.
- 지난 상담: 원하는 상담 찾기 성공률.
- 상담 상세: 상담 확인·계획 연결 성공률. 결론 또는 답변 원문·당시 맥락·출처 확인과 선택한 오늘 계획의 연결 저장·대상 확인을 모두 충족해야 성공이다.
- 상담 내용 남기기: 부수 제안 화면 1개, 상담 저장 성공률. 직접 입력한 내용·날짜·상담 상대가 정확히 저장되었는지 확인한다.
- 실제 상담 자료가 없는 조건에서 테스트용 예시는 가상으로 명시하고 실제 상담 기록과 구분한다.
- 성공 건수/시도 건수와 성공률을 함께 기록하며 미실시는 미측정이다. 실제 결과와 목표 수치는 미정이다.
