# 과업 소개 앱 미리보기 가독성 수정

2026-11-27 · AZTKS APPLY · 대상: tasks/의 7개 상세 소개 · 품질 기준: 높음

기존에는 화면 높이에 맞춰 기기 폭을 줄이고, 390px 앱 화면 전체를 transform으로 축소했다. 1440×1000 환경에서 목업 외곽은 320px였고 앱 글자와 버튼도 함께 작아졌다. 문제는 표시 내용의 누락보다 실제 표시 크기였다.

## 수정과 검증

- 데스크톱 목업 외곽 폭을 440px로 변경하고 높이에 따른 폭 축소를 제거했다.
- iframe의 transform과 고정 390px 폭을 제거했다. 앱은 실제 가용 폭에 반응하며 글자·버튼을 축소하지 않는다.
- 축소용 JavaScript를 제거했다. 낮은 데스크톱 화면에서는 목업 전체를 스크롤해 볼 수 있도록 고정을 해제한다.
- 모바일에서는 좌우 여백을 줄여 목업에 더 많은 폭을 배정했다.
- CSS 내용 해시를 사용하는 기존 배포 방식은 유지한다.

Chromium에서 7개 페이지 × 320×900, 390×900, 1366×768, 1440×1000의 28개 화면을 확인했다. 바깥 페이지와 앱 내부 가로 넘침 및 JavaScript 오류는 0건이다. 데스크톱 목업 폭 440px, 모바일 목업 폭 304/374px를 확인했다. 모든 화면에서 앱 본문 14px와 주요 행동 버튼 높이 48px가 축소 없이 표시됐다. 목업 안의 계획 저장 → 운동 시작도 통과했다. 데스크톱·모바일 대표 캡처를 직접 검토했다.
