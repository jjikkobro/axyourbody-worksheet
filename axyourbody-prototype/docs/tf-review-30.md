## 평가 방법

- 각 역할이 6개씩 제시한 **서로 다른 30개 시나리오**를 Chromium에서 기존안과 개선안에 각각 실행했다. 점수는 통과한 항목의 사전 지정 가중치(3~5) 합계다. 만점은 132점이다.
- 이 점수는 TF가 발견한 결함과 과업 완료 기준을 확인하는 **내부 시나리오 적합도**다. 실제 사용자 성공률, 의료적 효과, 서비스 품질의 절대 점수가 아니다.
- 기존안은 Git `a1bb114`의 HTML, 개선안은 아래 최종 파일이다. 시나리오와 결과는 `verification/tf-30-simulations.cjs`, `verification/tf-30-results.json`에 남겼다.
- 실행 조건: 로컬 `file://`, Chromium 오프라인 모드, 시나리오마다 저장소를 초기화. 이후 320·390·768·1440px의 5개 주요 화면을 추가 점검했다.

## 해석 범위

TF의 5명은 서로 다른 관점을 맡은 AI 에이전트다. 30회는 브라우저 기반 시나리오 실행이며 실제 사용자 30명 평가나 독립적인 임상 검증은 아니다. 핵심 과업 1~3 외 운동 일지·목표 편집, 실제 AI, 서버 동기화는 구현하지 않았다.
