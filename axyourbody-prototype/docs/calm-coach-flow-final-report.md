## 사용자에게 달라진 점

‘지금 어떤 상태인지 → 무엇을 누를지 → 무엇이 바뀌는지 → 어디에 저장됐는지’가 이어지도록 정리했다. 차분한 운동 코치 방향과 원자료의 의미를 유지했다.

| 상황 | 지금 할 수 있는 일 | 반영 범위 |
|---|---|---|
| 운동 전 | 계획을 확인하고 수치·몸 상태 변경, 전후 영향 확인, 저장 | 오늘 예정 계획. 수행 기록을 만들지 않음 |
| 계획이 저장 전 | 저장 또는 변경 폐기를 선택한 뒤 운동 경로 계속 | 선택하기 전 기존 계획·운동 여부 유지 |
| 운동 시작 후 | 실제 수행 입력·임시 저장·종료·일지 저장 | 시작 기준 계획과 실제 수행을 별도 보관 |

| 운동한 뒤 방문 | 이미 한 운동을 직접 기록 | 모르는 시작·종료 시각은 생성하지 않음 |
| 운동하지 않은 날 | 미실행 저장 또는 취소, 수행 기록으로 정정 | 정정 저장 전에는 기존 미실행 기록 유지 |

| 상담 참고 변경 | 계획 연결·해제, 취소·오류 후 재시도 | 상담 원문과 운동 수치는 유지 |
