## 프로필 3 · 박준혁 (남성 · 운동인) `m-athlete`

| 항목 | 내용 |
|---|---|
| 나이 · 직업 | 38세 · 스타트업 프로덕트 매니저 |
| 하루 일과 | 06:00 기상 → 06:30~08:00 웨이트 → 09:30~19:00 근무 → 주 2회 저녁 하이록스 훈련 → 23:00 취침 |
| 운동 수준 · 경력 | 웨이트 트레이닝 8년, 하이록스 2년. 주 6일 훈련(웨이트 4일 + 하이록스 2일) |
| 목표 (우선순위) | ① 골격근량 36.2kg → 37.5kg ② 백스쿼트 1RM(1회 최대 중량: 한 번만 겨우 들 수 있는 가장 무거운 무게) 115kg → 125kg ③ 하이록스 기록 유지(다른 목표를 방해하지 않기) |
| 현재 불편 3가지 | ① 목표 셋이 서로 충돌할 때(하이록스 다음 날 하체 훈련 등) 무엇을 우선할지 매번 혼자 계산한다 ② AI와 나눈 훈련·영양 상담이 대화창마다 흩어져 다시 찾을 수 없다 ③ 체성분 측정 조건이 매번 달라 수치 변화를 믿기 어렵다 |
| PT 경험 · 예산 | 주 1회 PT를 2년째 받는 중. 나머지 날은 셀프 훈련. 코치 피드백을 셀프 훈련에도 이어 쓰고 싶음 |
| 이 사람이 원하는 한 문장 | "코치 없이 하는 날에도 코치가 옆에 있는 것처럼 판단해 주면 좋겠다." |
