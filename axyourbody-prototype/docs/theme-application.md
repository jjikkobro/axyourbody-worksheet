# 세 테마 적용과 비교 기준

> 최초 시안 제작 전의 비교 계획을 보존한 문서다. 아래 ‘미제작’·‘미확정’은 당시 상태이며, 현재 제품의 디자인 기준은 [DESIGN-axyourbody.md](../design/DESIGN-axyourbody.md)를 따른다.

이 문서는 앱 적용 제안이다. design/의 다운로드 원문 3개는 별도로 보존한다.

| 테마 | 기준 파일 | 적용 방향 | 결과 파일 |
|---|---|---|---|
| calm-coach | design/DESIGN-calm-coach.md | 크림·자연색과 여유 있는 카드로 오늘 계획·판단 설명의 가독성 비교 | prototype-first-calm-coach.html |

## 공통 기준

- SCREEN_SPEC.md의 필수 7개 화면과 과업 1~3을 모두 기준으로 삼는다. A01은 부수 제안이다.
- 문구·수치·날짜·샘플·과업 완료 조건을 같게 유지한다. 실제 사용성 평가 결과는 아직 없다.
- 색·글꼴·간격·정보 밀도뿐 아니라 영역 배치·요소 유형도 달리할 수 있다. 필수 동작과 흐름은 보존한다.
- 한국어 본문은 읽기 편한 고딕체를 선택한다. 원문 전용 영문 폰트를 한국어에 그대로 강제하지 않는다. 실제 사용할 폰트와 세부 값은 아직 확정하지 않았다.
- 원문 웹사이트의 사진 중심 홍보 영역은 앱 과업에 필요한 경우에만 참고한다. 브랜드 로고는 복제하지 않는다.
- 비교에서는 같은 날짜·과업으로 끝까지 눌러 본 뒤 가독성·판단 근거·저장 결과 확인·모바일 사용성을 기록한다.
- 외부 요소의 출처, 변경점, 다음 할 일을 버전 기록에 남긴다.
