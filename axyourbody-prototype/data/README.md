# 가상 데이터 출처

- 대상: m-athlete, 기간: 2026-10-05~2026-11-01.
- 출처: https://github.com/wild-mental/ax-wave-uxui-wildmental/tree/main/datasets/m-athlete
- body.csv, workout.csv, meal.csv, sleep.csv는 로컬 교재 원본과 바이트 단위로 같게 복사했다.
- 실제 개인 기록이 아닌 가상 데이터다. 원본은 수정하지 않고 계산값·시연용 샘플과 구분한다.
- 운동 기록을 미래 계획으로, 훈련 시간을 대회 기록으로, 개별 동작 요약을 개별 세트 관찰값으로 바꾸어 해석하지 않는다.
- 상담 원문·미래 운동 계획은 이 CSV에 없다. 시연에 필요하면 별도 가상 예시로 표시하고 세 테마에서 동일하게 쓴다.
