[DESIGN-axyourbody.md](DESIGN-axyourbody.md)는 2026-11-27 현재 로컬 HTML 프로토타입에서 추출했다. CSS 적용 순서와 390px·1440px의 브라우저 계산값을 확인했으며, 외부 브랜드 디자인 원문이 아니다. 실제 제품 구현·수정에는 이 문서를 우선 사용한다.

각 공개 페이지의 DESIGN.md 미리보기 코드 블록 전체를 HTML 엔티티를 해제하여 저장했다. 원문 내용을 요약하거나 앱에 맞게 고쳐 쓰지 않았다. 파일 이름만 이번 테마 이름으로 대응했다.

이 자료는 getdesign.md/VoltAgent가 관찰 가능한 브랜드 패턴을 분석한 참고 자료이며 브랜드 공식 디자인 시스템이나 제휴·보증 문서가 아니다. 개별 브랜드명·상표·전용 폰트는 각 소유자의 권리를 따른다. 폰트·로고 파일은 포함하지 않는다.

세 원문을 한 번에 읽어 섞지 말고 한 테마의 원문만 선택한다. 초기 테마 비교 이력은 ../docs/theme-application.md, 현재 제품 기준은 DESIGN-axyourbody.md와 ../SCREEN_SPEC.md를 따른다. 원문 마케팅 페이지의 큰 사진·헤드라인을 필수 앱 화면으로 추가하지 않는다.
